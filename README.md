# 全科期末急救 · ReviewCraft

> 全科复习资料生成器：把课件、教材、录音、往年题，变成一套**能直接打印**的复习资料——知识点汇总、章节练习、2–3 套模拟卷 + 答案。

**English name**: ReviewCraft

ReviewCraft 是一套给 **AI Agent** 用的工作流包（Skill），**不绑定任何客户端**：对话式 Agent、CLI Agent、IDE 里的助手、本地模型都可以，只要它能读文件、能跑命令。它不是一个独立程序，而是「流程 + 模板 + 校验脚本」：你先给它课程材料，它先提取真实考试情报，再产出 LaTeX 排版的复习资料。

---

## 它解决什么问题

大多数“AI 帮我出套卷子”的结果是：题型不对、没有留白、答案和题目混在一起、案例要学生自己翻书。ReviewCraft 把这些问题前置成规则：

1. **先提取考试情报，再动笔**
   题型分值、范围与排除章节、命题依据（教材 / PPT / 两者 / 往年题）、重点、术语差异。没有情报就先问，不猜。

2. **大题必须留答题空间**
   简答 3–4cm、论述 9–12cm、案例每小问 3–4cm，写进规则并由脚本检查；没有留白的卷子直接判失败。

3. **案例题自包含**
   500–900 字，学生不需要教材或原始案例 PDF；案例框与问题不分页。

4. **按课程类型换打法**
   工科看步骤分与单位，文科看论证与文本证据，思政看官方表述与踩点，商科看法学看涵摄、医学看鉴别诊断。

## 输出什么

默认 2 + 2N 个文件（N = 模拟卷数量，默认 3，可选 5）：

| 文件 | 内容 |
|---|---|
| `01_知识点汇总.pdf` | 按章考点、对比表、易错点、考前速览 |
| `02_章节练习.pdf` | 分章练习，答案随题附后 |
| `03_模拟卷A.pdf` + `04_模拟卷A_答案.pdf` | 第一组章节（基础） |
| `05_模拟卷B.pdf` + `06_模拟卷B_答案.pdf` | 核心章节 |
| `07_模拟卷C.pdf` + `08_模拟卷C_答案.pdf` | 综合/跨章 |
| `09_模拟卷D.pdf` + `10_模拟卷D_答案.pdf` | 提高卷（可选） |
| `11_模拟卷E.pdf` + `12_模拟卷E_答案.pdf` | 挑战卷（可选） |
| `NN_课本OCR_考点章节/` | 扫描版教材的文字版（可选） |
| `_tex源文件/` | 全部 `.tex`，可自行改题重编译 |

答案文件逐问给**评分点**，不是整段范文。

### 难度阶梯

说“多来几套，最后两套难一点”就会加 D/E。难度不是靠偏题，而是按四个维度抬：

| 维度 | A/B/C | D 提高 | E 挑战 |
|---|---|---|---|
| 题干信息 | 完整 | 有干扰项 | 冲突或缺失，要自己假设 |
| 使用框架 | 1 个 | 2 个，需比较 | 3 个，需说明适用边界 |
| 设问动词 | 说明/分析 | 比较/应用 | 评价/决策/预测 |
| 答案要求 | 要点 | 论证 | 反方 + 取舍 + 落地 |

D/E 仍严格限定在考试范围内。

## 核心设计

### 1. 命题依据是变量

不同课不一样：有的以教材为准，有的以 PPT 为准，有的看往年题。Skill 会记录 `textbook / PPT / both / past papers`，术语主次跟着走：

- 教材为准 → 教材说法为主，课件说法括号备注
- PPT 为准 → 反之
- 两者/混合 → 用题干里的说法，附术语对照

### 2. 情报分级

| 手上有什么 | 能推出什么 |
|---|---|
| 完整录音/转录 | 题型、范围、排除、重点、术语 |
| 教学大纲 | 章节、权重、有时有题型 |
| 近 3–5 年真题 | 题型、风格、重复考点 |
| 只有课件 | 考点、术语、重点标记 |
| 只有教材 | 章节结构，题型未知 |
| 什么都没有 | 只问两个问题：题型、范围 |

### 3. 课程类型不同，卷子不同

| 类型 | 评分逻辑 | 致命错误 |
|---|---|---|
| 工科 | 步骤分：公式→代入→结果→单位 | 只写结果、单位错、图无标注 |
| 文科 | 观点 + 论据 + 结构 + 表达 | 罗列不论证、无文本证据 |
| 思政 | 踩点给分，关键词必须官方表述 | 口语化、自由发挥、引用错 |
| 商科 | 框架 + 案例事实 + 建议 | 只背理论不结合案例 |
| 法学 | 结论 → 依据 → 涵摄 | 结论无依据、援引失效法条 |
| 医学 | 诊断 → 依据 → 鉴别 → 处理 | 漏鉴别诊断 |

详细打法见 `skills/latex-review-materials/references/course-types.md`。

## 怎么用

不需要安装任何客户端，也没有运行时依赖。三选一：

### 方式一：直接交给对话里的 Agent

把 `skills/latex-review-materials/` 文件夹（或其中的 `SKILL.md` + `references/`）拖进对话，或者让 Agent 读取这个目录，然后说：

```
按这个 skill 帮我做「战略管理」的复习资料，材料在 F:\课程\战略管理\
```

### 方式二：放进 Agent 的 skills / 规则目录

如果你的 Agent 支持自定义 skill、rules 或 instructions 目录，把 `latex-review-materials/` 整个复制进去即可。目录名保持 `latex-review-materials`，与 `SKILL.md` 的 `name` 字段一致；具体路径取决于你用的 Agent，不是固定的。

### 方式三：CLI Agent

把仓库路径直接告诉它：

```
读 C:\path\to\reviewcraft\skills\latex-review-materials\SKILL.md，
按里面的流程帮我做复习资料。
```

> 说明：这个仓库只包含 `SKILL.md`、Markdown 参考文档和一个 Python 校验脚本，没有二进制、没有服务端、没有账号体系，所以任何 Agent 都能直接用。

## 使用

直接给材料 + 一句需求：

```
F:\课程\战略管理\ 先看课件和考点录音，按考试题型出三套模拟卷，
最后一题用文件夹里的案例，大题下面留写答案的空白。
```

Agent 会先输出一张“考试情报表”让你确认（题型、范围、依据、重点），再开始生成；如果你没提供题型，它会先问。

生成后建议流程：

1. 用 `references/quality_check.py` 过一遍所有 `.tex`
2. `xelatex` 编译两遍
3. 检查每份 PDF 的页数与留白
4. 把 PDF 和 `_tex源文件` 一起交付

## 依赖

| 依赖 | 用途 | 必需 |
|---|---|---|
| TeX Live（xelatex + ctex/fandol） | 编译 PDF | 是 |
| Python 3.9+ | 质量检查脚本 | 是 |
| PaddleOCR + onnxruntime-gpu | 扫描版教材 OCR | 可选 |
| ffmpeg / whisper | 录音转写 | 可选 |

OCR 参考速度：200 dpi 下 GPU（RTX 4070）约 1.5 秒/页，CPU 约 30 秒/页。

## 质量检查覆盖什么

`quality_check.py` 会检查：

- `enumerate` 是否配对
- tcolorbox 标题里是否有嵌套 `[` 或**英文逗号**（会触发 pgfkeys 报错）
- 试卷是否留了答题空间（`\vspace` 少于 3 处判失败）
- 试卷里是否混入了“参考答案/评分标准”
- `fancyhdr` 是否混入中文
- 是否使用了 emoji（LaTeX 不支持）

---

## 不做什么

- 不替代你的课程材料：没有课件/教材/录音，它只能给通用模板。
- 不保证押中题：它按“考试情报 + 课程重点”组织，不预测具体题目。
- 不生成答案以外的“标准答案”：文科与思政的答案给要点与评分点，不是唯一解。
