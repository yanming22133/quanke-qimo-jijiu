# `/review-notes` · 单独生成知识点汇总（+ 可选速查卡）

仅执行 `skills/latex-review-materials/SKILL.md` 中的知识点梳理模块，适合已有题库、只想系统梳理教材/课件核心考点的场景。

## 执行步骤

1. **快速情报确认**：提取或询问考试范围、排除章节、命题依据（教材/PPT/两者）与术语口径（最多 3 个问题）。
2. **分章精读与星级标注**：读取全部考试范围内材料，提炼每章核心概念、框架、公式/模型、对比表、易错点与术语对照。
3. **编译交付**：
   - 生成 `01_知识点汇总.pdf`（默认配 6–15 幅 TikZ 图，使用省墨讲义或用户指定版式）及 `_tex源文件/01_知识点汇总.tex`。
   - 若用户指定 `--with-card` 或要求速查卡，额外生成 1 页 A4 `13_考前速查卡.pdf`。
   - 编译前运行 `references/quality_check.py` 检查语法与排版。
