# `/review-fix` · 错题复盘与定向补弱卷

仅执行 `skills/latex-review-materials/references/review-mode.md`（Mode B），适合刷完模拟卷或发现某几章薄弱时的精准提分。

## 执行步骤

1. **逐题诊断**：读取用户上传的答卷（照片/PDF/文本）与标准答案，逐题判对错并标注错因（概念不清 / 方法不会 / 计算失误 / 审题偏差 / 步骤缺失 / 时间不够 / 空白）；若未传答卷、直接指定薄弱章节，则按单点阶梯补弱。
2. **知识掌握度映射**：更新各知识点掌握度（红 / 黄 / 绿）。
3. **定向产出**：
   - `复盘报告.pdf`（错因统计与红黄绿热力表）
   - `补弱卷.pdf` + `补弱卷_答案.pdf`（每个红点配 2 道变式题 + 1 道综合题，换情境不抄原题）
   - `15_错题本.pdf`（可选累积错题清单）与可选 `知识点补丁.pdf`。
