# 复习计划：按剩余天数倒排（countdown planner）

> 目标：不是“把资料排满”，而是**在剩余天数内，把有限小时分配到最能提分的地方**，并且每天知道“打开哪个文件、做哪几题、做完拿什么检查”。

## 1. 什么时候生成

- 用户说“还有 N 天考试”“帮我排复习计划”“每天能学 X 小时”。
- 考试在 14 天内，且已有知识点汇总 / 章节练习 / 模拟卷中的至少两类。
- 用户给了红点（薄弱知识点）、目标分数、每天可用时间。

不生成的情况：考试还有 1 个月以上，且用户没有明确要计划；此时先做资料，不排日计划。

## 2. 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| `course` | 是 | 课程名 |
| `exam_date` | 是 | `YYYY-MM-DD`，考试当天 |
| `today` | 否 | 默认系统日期 |
| `hours_per_day` | 是 | 每天可用小时（净学习时间，不含吃饭/休息） |
| `target_score` | 否 | 目标分，用于决定“保基础”还是“冲难题” |
| `topics` | 是 | 知识点/章节列表，每个含权重、掌握度、资料位置 |

> 某天不能学：把 `hours_per_day` 按周平均下调，或在生成后手动删掉那天的 block；不要假装那天能学 6 小时。

`topics` 每项：

```json
{
  "name": "ISM 规范方法",
  "weight": 5,
  "level": "red",
  "type": "calc",
  "materials": "知识点汇总 ch3；章节练习 3.2；全真卷 1/3/5 综合题"
}
```

- `weight`：考试权重 1–5。按题型分值、老师划重点、历年频次估。
- `level`：`red` 不会 / `yellow` 不熟 / `green` 会但慢。
- `type`：`calc` 计算、`concept` 概念、`mixed` 综合、`case` 案例。
- `materials`：必须写到“文件名 + 章节/题号”，否则计划会变成空话。

## 3. 输出

| 文件 | 用途 |
|---|---|
| `复习计划.pdf` | 打印版：倒计时、每天三块、打勾框、红黄绿清单 |
| `复习计划.md` | 可编辑版：每天任务清单，手机/Notion 可用 |
| `plan.json` | 机器可读：输入 + 计算结果，方便改日期后重排 |

生成命令：

```powershell
python references/make_plan.py --input plan.json --out 复习计划
xelatex 复习计划.tex
xelatex 复习计划.tex
```

## 4. 算法（7 步）

### Step 1：算天数

```
days_left = exam_date - today          # 不含考试当天
study_days = days_left - 1             # 最后 1 天只复盘，不学新内容
```

- 若 `days_left <= 0`：只生成“考前 3 小时急救单”，不排多天计划。
- 若 `days_left == 1`：今天只做“错题 + 速查卡 + 1 套限时卷”，不再开新章。
- 若 `days_left >= 2`：正常排。

### Step 2：算可用小时

```
total_hours = study_days × hours_per_day × 0.85
```

`0.85` 是 slippage buffer：计划一定会有意外，不要把 100% 排满。

### Step 3：算知识点优先级

```
score_i = weight_i × level_multiplier_i
level_multiplier = red 1.6 / yellow 1.2 / green 0.7
```

归一化：

```
share_i = score_i / Σ score
hours_i = total_hours × share_i
```

规则：
- `red` 至少给 2 个独立 block（学 1 次 + 练 1 次），不能只读一遍。
- `green` 只安排限时练和间隔复习，不再看讲义。
- 老师明确说“不考/低频”的，权重降到 0.3，只留概念，不排计算。

### Step 4：分三个阶段

| 剩余天数 | 基础回顾 | 题型训练 | 限时模拟 + 错题 |
|---|---|---|---|
| ≥10 天 | 40% | 35% | 25% |
| 5–9 天 | 30% | 40% | 30% |
| 3–4 天 | 20% | 45% | 35% |
| 2 天 | 0 | 50% | 50% |
| 1 天 | 0 | 0 | 100% |

“基础回顾”不是从头看书，而是：**看知识点汇总的本章 + 画一张 A4 结构图 + 做 5 道基础题**。
“题型训练”是：**按题型集中练**（如 ISM 只练分层、SD 只练列表），不是整套卷。
“限时模拟”是：**整卷或半卷，计时，做完立刻对答案**。

### Step 5：每天三块

把 `hours_per_day` 拆成 3 块，默认比例 40% / 35% / 25%：

| 块 | 时长（以 6h/天为例） | 任务类型 | 产出 |
|---|---|---|---|
| 上午 | 2.4h | 主攻 1 个红/黄点：学 + 例题 | 一张 A4 结构图 + 3 个自测问题 |
| 下午 | 2.1h | 对应练习 / 半套卷 | 做题 + 红笔订正 |
| 晚上 | 1.5h | 间隔复习 + 错题 | 错题本 3 条 + 明天 3 个问题 |

如果 `hours_per_day <= 3`：只保留“上午主攻 + 晚上回顾”，练习并入上午。
如果 `hours_per_day >= 8`：加一个“下午第二块”，但每块不超过 2.5h，块间休息 15 min。

### Step 6：间隔重复

每个知识点在以下节点各出现一次（能排下就排）：

```
首次学习 D
→ D+1 回顾（10 min：遮住答案，复述框架）
→ D+3 变式题（20 min：换问法/换数字）
→ D+7 混合题（30 min：和别的知识点混在一起）
```

天数不够时压缩为 `D → D+1 → D+3`；只剩 2 天时只做 `D → D+1`。
回顾 block 不占主攻时间，放在晚上或碎片时间。

### Step 7：检查点与重排

脚本会把**最后 1 个学习日**固定为“限时卷 + 订正”，最后 1 天（考前一天）只复盘。
如果只剩 2 天：第 1 天上午“高频点速过”，下午整卷限时；第 2 天速查卡 + 错题。
排不下的低权重知识点不会硬塞进主块，而是在表里标“只进速查”，并在晚上用 10 分钟过一个定义。

每天结束前 10 分钟做“3 问自测”：

1. 今天这个知识点，能不能不看书画出结构图？
2. 今天错的题，错因是“不会 / 不熟 / 看错 / 时间不够”哪一类？
3. 明天的 3 个问题是什么？

重排规则：
- **某天没完成**：不要第二天双倍补。删掉优先级最低的 1 个 block，保留间隔复习。
- **模拟卷低于 70%**：不要立刻再刷一套；第二天插入“2 个红点补弱 + 1 组基础题”。
- **连续两天完不成**：把 `hours_per_day` 下调 1h，重跑计划；计划要服从现实。
- **新增资料/老师划重点**：更新 `topics` 的 `weight`，重跑 `make_plan.py`。

## 5. 不同天数的骨架

### 14 天以上（三轮）

- 第 1–5 天：基础回顾，按章过知识点汇总 + 画结构图。
- 第 6–10 天：题型训练，按题型刷章节练习 + 全真卷的前半。
- 第 11–13 天：限时模拟，每 2 天 1 套整卷 + 当天对答案。
- 第 14 天：错题 + 速查卡，不开新章。

### 10 天（两轮半）

- D1–D3：高频章基础 + 结构图。
- D4–D7：题型专项（计算/综合/简答各 1 天）。
- D8–D9：2 套限时卷 + 错题。
- D10：速查卡 + 错题。

### 7 天（一轮 + 冲刺）

- D1–D2：红点 1–2 个，学 + 基础题。
- D3：变式题 + D1 回顾。
- D4：半套限时卷 + 订正。
- D5：第二组红点 + 综合题。
- D6：整套限时卷 + 错题。
- D7：速查卡 + 错题 + 早睡。

### 5 天

- D1：最高权重章：结构图 + 基础题。
- D2：第二权重章 + D1 变式。
- D3：题型专项（综合题/计算题）。
- D4：整套限时卷 + 订正。
- D5：错题 + 速查卡 + 1 套半卷。

### 3 天

- D1：全部红点补丁 + 1 套基础卷（只做基础题）。
- D2：变式题 + 错题重做 + 综合题模板。
- D3：1 套限时卷 + 速查卡 + 错题。

### 2 天

- D1：高频清单 + 1 套整卷（计时）+ 订正。
- D2：错题 + 速查卡 + 只看不写新题。

### 1 天

- 上午：速查卡 + 错题本（2h）。
- 下午：1 套半卷（1.5h）+ 订正（1h）。
- 晚上：只看错题 + 公式，23:00 前睡。

### 考试当天早上

- 只看速查卡和错题本，不做新题。
- 提前 40 分钟到考场；带齐证件、笔、计算器（若允许）。

## 6. 计划表格式

`复习计划.md` 每天一块：

```markdown
## Day 2 · 11-19（还剩 3 天）
目标：ISM 分层不丢分；SD 列表不错行

- [ ] 上午 2.5h｜ISM 规范方法：A→M→分层
      资料：知识点汇总 ch3；全真卷 3 综合题
      产出：默写 R/A/C 表和 L1/L2
- [ ] 下午 2h｜SD 库存：方程 + 7 期表
      资料：专项突破 3.4；全真卷 1 综合题
      产出：独立算对 7 期，错 0 行
- [ ] 晚上 1h｜间隔复习：Day 1 的 ISM + 错题 3 条
```

`复习计划.pdf` 表格列：

| 日期 | 倒计时 | 时段 | 任务 | 资料/题号 | 分钟 | 完成 |
|---|---|---|---|---|---|---|

## 7. 红黄绿清单

计划第一页放一张表：

| 知识点 | 权重 | 掌握度 | 下次复习 | 最怕的题型 |
|---|---|---|---|---|
| ISM 规范方法 | 5 | 红 | D2 / D4 | 分层、骨架 |
| SD 库存 | 5 | 黄 | D2 / D5 | 7 期表、曲线 |
| 霍尔/切克兰德 | 4 | 绿 | D6 | 对比简答 |

“最怕的题型”一列很重要：它决定练习是“做整套”还是“只做该题型”。

## 8. 反模式

| 错误 | 后果 | 改法 |
|---|---|---|
| 每天排满 10h | 第 2 天崩 | 按 0.85 折减，留缓冲 |
| 只排“看书” | 不会做题 | 每块必须有输出（图/题/复述） |
| 最后一天开新章 | 焦虑且记不住 | 最后一天只复盘 |
| 模拟卷连刷 3 套 | 没时间订正 | 做 1 套 + 订正 1.5h |
| 错题只抄不看 | 下次还错 | 错题本按“错因”分类，3 天后重做 |
| 计划没有题号 | 打开文件不知道做哪 | 写到“文件名 + 章节/题号” |

`references/make_plan.py`：

`plan.json` 最小示例：

```json
{
  "course": "管理系统工程",
```

## 10. 质量检查

- [ ] 每天总分钟数 ≤ `hours_per_day × 60`。
- [ ] 每个红点至少出现 2 次（学 + 练），且有一次在 D+1 或 D+3。
- [ ] 最后 1 天没有新知识点。
- [ ] 每个任务都有“资料/题号”和“产出”。
- [ ] 至少 1 套整卷是限时完成的。
- [ ] 计划表有“完成”勾选框。
