# Course-type playbook

The five templates in SKILL.md are the minimum. This file adds the details that decide whether a paper feels like the real exam.

---

## 1. 思政 / 政治理论课（最容易写错的一类）

**What is being tested**: accuracy of official formulations + ability to apply them, not personal opinion.

**Authoritative source**: textbook + latest official documents (会议精神、重要讲话). If they conflict, the newer official document wins; note it.

**Question types**: 单选、多选、判断、简答、材料分析、论述。

**Answer template (简答/论述)**:
1. 定位：属于哪个理论/哪个板块（1 句）
2. 原文表述：教材或文件的规范表述（核心得分点）
3. 展开：为什么 / 是什么 / 怎么做（三层）
4. 联系实际：结合材料或时政（1--2 句，不要喧宾夺主）

**Marking**: 踩点给分。关键词用官方术语才得分；同义口语表述通常不给分。

**Must do**:
- 建一个“表述对照表”：口语说法 → 规范说法（如“以人民为中心”不能写成“为老百姓着想”）。
- 多选题标注“少选得部分分、错选不得分”（按本校规则调整）。
- 时政范围限定在近 12 个月，超出范围要在卷首说明。
- 所有引用不确定时标“以教材原文为准”，不要编造文件名或日期。

**Fatal mistakes**:
- 自由发挥、写成议论文；引用错会议/文件；使用已过时的表述；观点与教材不一致。

**Answer space**: 简答 8--10 cm；材料分析 12--15 cm；论述整页。

## 2. 工科（计算 + 画图 + 设计）

**What is being tested**: 能否在给定条件下算出正确结果，并写得规范。

**Question types**: 选择、填空、简答、计算、画图、设计/分析。

**Paper must include**:
- 公式表 / 常数表（若考试允许）
- 明确说明计算器、单位、有效数字要求
- 画图题给坐标纸或空白网格（半页）

**Marking**: 步骤分——公式 30%、代入 30%、结果 30%、单位/量纲 10%（各校略有差异，按老师习惯）。

**Answer space**: 计算 8--12 cm；证明 10--12 cm；画图半页；设计题整页。

**Fatal mistakes**: 只写结果；跳步；单位错；图中无标注/无刻度；近似条件未说明。

**Summary style**: 每个公式给“适用条件 + 符号含义 + 常见变形”，比推导过程更重要。

---

## 3. 文科（文学/历史/哲学/社会学）

**What is being tested**: 概念准确 + 论证能力 + 文本/史料证据。

**Question types**: 名词解释、简答、材料分析、论述、作品分析。

**Marking dimensions**: 观点（是否切题、是否有判断）、论据（文本/史料/理论）、结构（层次）、表达（学术语言）。

**Answer file**: 给“要点 + 可接受的其他观点”，不要只给一个标准答案；文科允许多元，但要求论证。

**Answer space**: 名词 4 cm；简答 8 cm；材料分析 12 cm；论述 1.5 页。

**Fatal mistakes**: 罗列史实不论证；用现代概念套古代文本（时代错置）；引文无出处；把“感想”当“分析”。

**Summary style**: 概念 + 背景 + 代表观点 + 争议 + 可能的论述题角度。

## 4. 商科 / 管理（本课程属于这一类）

**Question types**: 选择、简答、案例分析、论述。

**Case answer template**: 判断（用了哪个框架/属于哪类）→ 依据（案例事实 + 理论）→ 建议（可执行）→ 风险/边界。

**Marking**: 框架匹配 40%、案例事实 30%、结论与建议 30%。

**Answer space**: 每小问 3--4 cm；论述整页。

**Fatal mistakes**: 只背理论不结合案例；建议空泛（“加强管理”）；忽略反例与风险。

---

## 5. 法学

**Question types**: 选择、名词解释、简答、法条分析、案例分析。

**Case method**: 结论 → 法律依据（法条/司法解释）→ 涵摄（事实对应构成要件）→ 结论。

**Marking**: 结论 20%、依据 40%、涵摄 40%。

**Fatal mistakes**: 结论对但无依据；援引失效法条；混淆构成要件。

---

## 6. 医学 / 生物

**Question types**: 选择、名词解释、简答、病例分析、实验设计。

**Case method**: 诊断 → 诊断依据 → 鉴别诊断 → 处理原则。

**Marking**: 诊断 30%、依据 40%、鉴别与处理 30%。

**Fatal mistakes**: 只写诊断不写依据；遗漏鉴别诊断；处理原则与指南冲突。

---

## 7. 投资学 / 金融

**What is being tested**: 会不会用公式和假设算出可解释的结果，而不是背定义。

**Question types**: 选择、判断、计算（货币时间价值、债券定价与久期、股票估值、CAPM/WACC、期权）、简答、案例/论述。

**Calculation template**:
1. 画时间轴（现金流发生的时点）
2. 写公式（注明符号与单位）
3. 代入（年化/期间利率统一）
4. 结果（保留 2--4 位小数，注明单位）
5. 一句解释（结果的含义与假设）

**Paper must state**: 单利/复利、计息频率、税率、费率、四舍五入规则、是否给公式表。

**Answer space**: 10--14 cm；多期/多资产题整页。

**Marking**: 时间轴/公式 30%、代入 30%、结果 30%、解释 10%。

**Fatal mistakes**: 年化利率与期间利率混用；税前/税后混用；久期符号错；把期权内在价值当总价值；忽略中间现金流。

**Difficulty ladder**: 单期单资产 → 多期/多资产 → 需要自己设定假设（如增长率、折现率）并说明敏感性。

---

## 8. 计算机 / 数据科学

**What is being tested**: 能否写出正确、可运行、复杂度可接受的代码，并能解释取舍。

**Question types**: 选择、填空、简答、写代码/伪代码、算法设计、复杂度分析、找 bug。

**Programming template**:
- 题目描述（输入、输出、约束）
- 1--2 组样例（含一个边界样例）
- 要求：语言、是否允许伪代码、时间/空间限制
- 答题区：20--30 行（纸面）或代码框
- 追问：复杂度、边界情况、改进方向

**Answer space**: 20--30 行；再加 2--4 cm 写复杂度分析。

**Marking**: 正确性 50%（含边界）、复杂度 20%、结构/风格 20%、清晰度 10%。

**Fatal mistakes**: 只过样例；忽略空输入/重复元素/溢出；复杂度不达标；不写复杂度。

**Difficulty ladder**: 直接实现 → 加约束/优化 → 对抗性输入 + 复杂度证明。

## Cross-type checklist

- [ ] 题型与真实考试一致（Step 0）
- [ ] 大题类型匹配学科：计算/证明/画图/编程，不是一律案例（SKILL §3.5.2）
- [ ] 计算题给了公式表、单位、假设与舍入规则
- [ ] 编程题给了样例、约束、边界与复杂度要求
- [ ] 答案空间按类型给足（本文件 + SKILL §3.5.1）
- [ ] 评分逻辑写进答案文件（步骤分 / 踩点 / 论证维度 / 测试点）
- [ ] 术语以命题依据为准（§0.2）
- [ ] 该类型的“致命错误”在讲评或答案里点出来
